# Patches do Navegador

Este diretório contém somente diferenças permanentes em relação ao Chromium upstream.

## Convenção

- `0001-descricao-curta.patch`
- `0002-outra-mudanca.patch`

A ordem oficial fica no arquivo `series`.

Antes de adicionar um patch, verifique se a mesma mudança pode ser feita por configuração, preferência ou argumento GN.

Cada patch deve ter um objetivo pequeno e uma mensagem de commit/descrição que explique por que ele existe.
